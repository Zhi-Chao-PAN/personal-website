# Portfolio content evidence

Content review date: **2026-09-23**. Canonical content: `data/portfolio.json`.

This ledger records the evidence used to rewrite the portfolio. It is an editorial record, not a fresh certification of every project or hosted deployment. Public repositories, their documentation, and specified CI runs were inspected. The original portfolio editorial pass made no paid model call or new benchmark run and did not inspect private projects. Later AutoResearch updates added the separately documented AI-agent runs.

## Editorial contract

- The catalog contains **14 cases: 9 with public source repositories, 1 public application-evidence case, 4 private overviews, and 3 hosted destinations**. A hosted destination is not necessarily an anonymous working demo. Model Eval Studio uses invited access.
- Flagship order: LaunchLens AI, LLM Evaluation Playbook, AI CLI Orchestrator. Selected: AutoResearch Evidence Pack, Model Eval Studio, Structure-Aware RAG, Battery Prognostics. The remaining seven cases are archive entries.
- English and Chinese describe the same capabilities, outcomes, and limits. Both use the same evidence links and verification date.
- `verifiedAt` records the date the editorial evidence was inspected. It does not promise that all external CLIs, model providers, or deployed features were exercised on that date.
- Personal-role copy follows the owner-approved description for this update: lead requirements and tradeoffs, use AI-assisted implementation, and review and iterate. Repository ownership alone is not used to claim that the author manually wrote every core component, independently produced every result, or did all work without assistance.
- Public source describes implemented or documented capability. Historical reports describe a bounded result. Fixed examples illustrate behavior. Live functionality requires separate current execution evidence. These categories must stay visible in demo and case-study interfaces.
- Existing customer, batch, feedback-volume, time-spent, adoption, revenue, and performance numbers are not promoted without a suitable scope and evidence. The portfolio does not add inferred personal history or new private-project details.
